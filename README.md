# Ambience — Trilha Sonora Sincronizada (releases)

Distribuição do módulo **Ambience** para o Foundry VTT (v12 / v13 / v14, qualquer sistema):
uma biblioteca de trilhas que mistura arquivos de áudio locais e vídeos do YouTube
e toca tudo sincronizado para a mesa, com cenas rápidas, sugestões dos jogadores e
um widget que encolhe e encaixa num canto da tela.

Este repositório contém só os pacotes publicados. O código-fonte é mantido em
outro repositório.

## Instalação

No Foundry, vá em **Add-on Modules → Install Module** e cole no campo
*Manifest URL*:

```
https://github.com/dominique-carvalho/ambience-foundryvtt-releases/releases/latest/download/module.json
```

Depois, ative o módulo **Ambience** no mundo. O manual de uso vem junto com o
módulo (`MANUAL.md`).
